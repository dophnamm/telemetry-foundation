05

Every product installs the same kit: the SDK in its applications, a Collector agent on each node and a gateway per cluster. What changes is where the gateway sends data. Products that OPSWAT runs (A and B) use hub mode and stream OTLP to the hub, one tenant per product, which gives the company-wide view and lets us compare SLOs across products. Customer installs use standalone mode: the data stays on site in a local backend with its own UI and the customer's SIEM. A connected customer can opt in to send aggregated metrics to the hub and can upload support packages. An air-gapped customer exports the support package as a file, through a shared folder. Solid lines are always on; dashed lines are optional or manual.
