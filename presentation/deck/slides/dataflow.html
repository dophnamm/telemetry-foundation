Telemetry Foundation

06

Inside one cluster, every application sends three lanes to the agent on its node. Lane one: all logs, including DEBUG, go into the flight recorder, which keeps the last 15 minutes on the node's disk and nothing else; it only leaves the node when the diagnostics service builds a support package on demand. Lane two: logs, metrics and traces pass the log-level filter, so only the levels an admin selected go on to the gateway. Lane three: OCSF security events travel on their own port and durable queue and are never filtered or sampled. The gateway masks personal data when anything leaves the site and routes by mode: to the local backend in standalone mode, to the OPSWAT hub in hub mode, and OCSF events to the customer's SIEM. The navy box, the agent, is where most of the Foundation logic lives.
