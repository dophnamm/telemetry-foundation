The same pipeline, with each Foundation block placed where it lives. F1, the telemetry standard, is the band underneath: it applies to every signal from every component, so data from any product can be filtered and compared. F2 is the thin SDK inside the applications. F3 is the Collector agent on every node, our custom build with the flight recorder, the log-level filter and the OCSF lane. F4 is the log-level configuration that the agent watches and applies in under ten seconds, with expiry and an audit event for every change. F5 is the OCSF event format and delivery to the customer's SIEM. The gateway is drawn dashed because it belongs to the next sub-project; Foundation only defines what it receives.
